# Dashboard 页面使用说明书

## 1. 文档目标

本说明书用于指导你正确使用 AgentOS 的 Dashboard 页面，适用于本地预览环境。

主要覆盖：
- 正确打开页面的方法
- 登录与基础操作
- 工具区（Active Tools）交互
- 常见问题与排查

---

## 2. 正确打开方式（非常重要）

请使用浏览器打开下面这个地址：

http://127.0.0.1:3000/dashboard-redesign.html

不要用本地文件直开（例如双击 html 文件或 file:/// 开头地址）。

原因：
- 页面需要调用后端接口（如 /api/login、/api/agent/run）
- 本地文件直开会导致跨域或网络请求失败
- 常见表现就是登录弹窗出现“网络错误，请重试”

---

## 3. 启动本地服务

在项目目录启动服务后再访问页面。

方式 A（推荐，在 IntelliCodeAssistant 目录中执行）：

```powershell
cd d:\新建文件夹\IntelliCodeAssistant
node preview_server.js
```

方式 B（端口被占用时自动重启）：

```powershell
cd d:\新建文件夹\IntelliCodeAssistant
npm run web:restart
```

服务正常时，可通过健康检查确认：

http://127.0.0.1:3000/health

若返回类似 {"ok": true}，说明服务可用。

---

## 4. 首次使用流程

1. 打开页面：
   - http://127.0.0.1:3000/dashboard-redesign.html
2. 点击右上角 Login
3. 输入演示账号：
   - 用户名：admin
   - 密码：123456
4. 点击登录按钮
5. 登录成功后，右上角按钮会变为 Logout

---

## 5. 页面功能说明

## 5.1 中央工作区（聊天/任务执行）

- 输入框：在底部输入任务需求
- 发送方式：
  - 点击发送按钮
  - 按 Enter 发送（Shift+Enter 可换行）
- 运行状态：
  - Idle：空闲
  - Running：执行中
- 执行结果：会显示 Agent 的运行过程与结果摘要

## 5.2 右侧 Active Tools 区

当前默认展示 3 个工具：
- Web Browser
- File Reader
- Report Gen

交互规则：
- 点击工具行可展开说明
- 再次点击可收起
- 同一时间只会展开一个工具
- 右上角会显示启用数量（例如 3 Enabled）

## 5.3 右上角账号按钮

- Login：打开登录弹窗
- Logout：清除本地 token 并退出登录状态

## 6. 常见问题排查

## 6.1 登录提示“网络错误，请重试”

优先检查以下 4 项：

1. 是否通过 http://127.0.0.1:3000/dashboard-redesign.html 打开页面
2. 是否启动了 preview_server.js
3. http://127.0.0.1:3000/health 是否可访问
4. 浏览器是否缓存了旧脚本（可强刷 Ctrl+F5）

## 6.2 preview_server.js 启动失败（EADDRINUSE）

说明 3000 端口已被占用。

处理方法：
- 使用 npm run web:restart 自动释放端口并重启
- 或先停止占用 3000 的进程后再启动

## 6.3 登录成功但无法运行 Agent

检查项：
- 浏览器本地是否有 token（键名：preview_demo_token）
- 请求 /api/agent/run 是否返回 401（说明 token 无效或过期）
- 重新登录再试

## 7. 快速自检清单

如果以下都满足，说明页面功能正常：

- 能打开 dashboard-redesign.html
- Login 可以成功
- 右上角状态变为 Logout
- Active Tools 三个工具都可展开/收起
- 输入任务后能看到 Running 状态与结果输出
